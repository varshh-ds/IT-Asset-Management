 IT Asset Management System (ServiceNow App)

**Description:**
A ServiceNow-based IT Asset Management System that automates the process of tracking organizational assets such as laptops, servers, and licenses.
The system ensures efficient asset allocation, automated email notifications upon assignment, and centralized reporting for asset utilization and maintenance.

---

### ⚙️ Features

* **Automated Email Notification:** Sends an email whenever an asset is assigned to a user.
* **Asset Lifecycle Tracking:** Tracks asset statuses — *Available, Assigned, In Use, Under Maintenance, Retired*.
* **Custom Tables:** `IT Asset` table for managing asset details.
* **Flows & Logic:** Configured Flow Designer logic to automate asset updates and notifications.
* **Dashboard Reports:** Visualizes the distribution and usage of assets.

---

### 🧩 Technologies Used

* **Platform:** ServiceNow (App Engine Studio)
* **Modules Used:** Flow Designer, Notifications, Data Tables, UI Forms
* **Version Control:** GitHub Integration with Scoped Application

---

### 🚀 How to Run

1. Open your ServiceNow **PDI (Personal Developer Instance)**.
2. Navigate to **System Applications → Studio → Import from Source Control**.
3. Use your repo link:

   ```
   https://github.com/varshh-ds/IT-Asset-Management.git
   ```
4. Once imported, open **App Engine Studio** → your app → test flow by assigning assets.
